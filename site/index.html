    THE COMPANY

    AWAITING DATA

    CyberPulse is run as a small newsroom company in Paperclip, the control plane: a CEO, desks that report to it, a monthly budget and a set of routines. Paperclip holds the org chart, wakes the agents and enforces budgets and approvals.

    Collection is code. The worker fetches every source, matches and scores what comes back and publishes the snapshot on its own clock, with no model in that loop, so a snapshot is still written when every agent is stopped. The agents add judgment, review and housekeeping on top.

    The names and faces are presentation. Authority comes from each agent's Paperclip role, permissions and budget.
